              Privacy & data

              For sensitive documents or shared computers. Keeps nothing about your documents in this browser (no drafts, recent files or session) and deletes what is already stored. Unsaved edits are lost if the page closes.

              Off by default. Keeps file and folder names (never contents) in this browser so you can reopen them, or restore your last session (tabs, active tab and scroll position), after a reload.

              On by default. While a file has unsaved changes, its full text is kept unencrypted in this browser's storage (never uploaded) so a crash, reload or closed tab does not lose your work. Saving or discarding removes the draft; drafts older than 14 days are deleted, and at most 20 are kept. Anyone using this browser profile can read them, and so can other pages from the same location (for local files in some browsers, any other local page).

              On by default. Once you edit a file, versions of it are kept unencrypted in this browser (never uploaded): the text as you opened it, each save, changes made on disk or by a restore or replace, and every five minutes while you edit. Files you only read are never stored. At most 50 versions per file and 1,500 in all, none larger than 1 MB; versions older than 60 days are deleted. Anyone using this browser profile can read them. Private mode turns this off and deletes them.
